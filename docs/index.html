Risks

Rules that shape the work

  • Only work built Oct 27 – Nov 4 counts. The baseline is imported once, tagged, and kept apart from new modules.
  • The repo is public: no story, characters, scripts or voice files in the repo or its history.
  • Judges use the live product, so every feature gets a cached fallback.
  • Avoid listed anti-projects (medical advice, basic RAG, simple image analysers, war or politics). Keep the framing a heist.
  • Unchecked: Vercel function duration limits, Muse Glimmer fit, model availability in my region.
